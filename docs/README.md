# boxxkite documentation

This directory is the repository's documentation map. The pages are grouped
by the question they answer:

| Section | Use it for |
| --- | --- |
| [Getting started](getting-started/) | Install the local runtime and make the first tool call. |
| [Guides](guides/) | Complete a task or choose a deployment/integration path. |
| [Reference](reference/) | Look up stable contracts, error shapes, and package-level APIs. |
| [Architecture](architecture/) | Understand the runtime's boundaries and the trade-offs behind them. |
| [Community](community/) | Contribute, discuss changes, follow releases, and report problems safely. |

## Recommended path

New to the repository? Follow [Getting started](getting-started/) from top to
bottom. It uses the local Docker Compose path and does not require a
Kubernetes cluster or a model-provider key. When you are ready for a framework
integration, choose an example from [the cookbook](../examples/).

For a quick map of the repository's packages, see [What's in this repo](../README.md#whats-in-this-repo).
For security reporting and the complete disclosed limitation list, see the
[security policy](../SECURITY.md).
