# Basic workflows

These examples show the direct runtime and hosted control-plane paths without
requiring an agent framework.

- [`raw_api/`](raw_api/) — sidecar HTTP calls with curl and `requests`.
- [`hosted_control_plane/`](hosted_control_plane/) — account, session, file,
  execution, and teardown flow.
- [`stateful_interpreters/`](stateful_interpreters/) — persistent Python and
  Node interpreter calls.
