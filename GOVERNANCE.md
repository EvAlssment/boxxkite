# Governance

## Current model

boxxkite currently has a single-maintainer governance model. The current
maintainer has final decision authority for project direction, releases,
contributions, and community moderation. Review routing is defined in
[`.github/CODEOWNERS`](.github/CODEOWNERS), which is the authoritative source
for the current maintainer rather than this document.

Contributors are encouraged to discuss substantial changes in an issue before
implementation. For a quicker, informal discussion, the project community is
also available on [Discord](https://discord.gg/JntfAx7cg5).

## Becoming a maintainer

Maintainers are invited by the current maintainer. Eligibility is based on
sustained, high-quality contributions and demonstrated stewardship of both the
project and its community. This can include thoughtful code review, reliable
maintenance work, constructive collaboration, and adherence to the project's
contribution and conduct expectations.

## Decisions and disagreements

The project aims to resolve decisions through open, good-faith technical
discussion. When contributors disagree, they should document the relevant
trade-offs in the associated issue or pull request. If consensus is not
reached, the current maintainer makes the final decision under the current
single-maintainer model.

Issue [#79](https://github.com/EvAlssment/boxxkite/issues/79) tracks a
proposal for a future formal BEP process. That process is not yet established;
until it is, changes to this governance model or other major project processes
are discussed and decided using the model described above.
